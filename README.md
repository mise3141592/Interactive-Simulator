인터랙티브 문제를 시뮬레이션할 수 있는 시뮬레이터를 출시합니다.

오른쪽 메뉴의 Releases 글자 밑에 "시뮬레이터 (Latest)"를 클릭하여 다운로드할 수 있습니다.

먼저 오른쪽 위 "변경" 버튼을 통해 파이썬 인터프리터를 지정해 주어야 합니다. 이미 지정되어 있다면 넘어가도 됩니다.  

그런 다음 정답 코드, 인터랙터, 비밀 시나리오 파일을 넣고 실행 버튼만 누르면 됩니다. 코드는 반드시 파이썬으로 작성해야 합니다. 오른쪽 아래 질의 횟수(정답 프로그램의 출력 횟수)가 표시됩니다.

인터랙터 파일은 위 폴더에서 확인할 수 있습니다.
